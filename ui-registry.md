# Brand assets

- Brand name: **Garments** in interface text; **GARMENTS** in uppercase print headings.
- Shared logo: `/logo.svg`, a navy square with a gold hanger and white G monogram.
- Browser icon: `app/icon.svg`, matching the shared logo.
- Preserve the existing Poppins typography, navy/blue palette, layout, and logo dimensions.
- Login, sidebar, invoices, refunds, purchases, and reports share this identity.

## Stock barcode

- Positive quantities display an authenticated Code 128 SVG beneath the SKU.
- Barcode previews use a white background, a 160px width, and a 48px height; preserve the barcode's quiet margins.
- The blue “Print labels” link opens a separate print sheet with an editable label count.
- Variant barcodes encode the variant SKU; restocking retains the same barcode.

## Invoice entry

- New invoices open directly in the walk-in form.
- “New Invoice” clears the entry fields while keeping the walk-in form visible.
- Do not introduce an invoice-type picker into this flow.
